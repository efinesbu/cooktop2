# Add MCP Server

## Workflow

1. Locate user-level or project-level MCP config.
2. Add the server entry with `url` or `command` + `args`.
3. Store credentials in environment variables.
4. Validate tool discovery and connectivity.
5. Document required variables and setup steps.
